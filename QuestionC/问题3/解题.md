
# 一、能否直接复用第1问模型？

**短答**：可以复用作为基线，但建议扩展。

理由：

* 你已用到孕周与 BMI，并且随机截距/斜率已捕获个体内变化，这正是做概率预测的合适起点。
* 但问题三要把更多协变量（身高、体重、年龄、质控指标、检测误差）和不确定性纳入决策，所以需要在模型上做若干补充或敏感性分析，至少把“重要混杂变量”和“误差结构”考虑进去。

# 二、如何在变量选择上权衡（BMI vs 身高/体重 vs 年龄 vs “等”）

1. **BMI 已包含身高+体重的信息**，如果你仅希望表达体型，保留 BMI 更简洁、临床可解释。
2. **当要拆解 BMI 的具体作用或检查共线性影响时**，可以在备选模型里用 `weight` 和 `height` 替代 BMI，看哪个模型解释力/预测性更好（用 AIC / CV / BIC 比较）。
3. **添加年龄**：应加。母体年龄是常见协变量，通常与生理指标、样本提交行为有关系。加入后检查其系数与显著性。
4. **“等” 的处理**（题目中的“等”意味着其它可影响项，例如 L、M、N、GC、draw\_index、采样中心等）：

   * 把与测序/观测误差相关的 QC 指标（L、M、N、GC）优先加入，因为它们会影响 σ（残差）或测量误差大小。
   * 若某些协变量高度共线（VIF>5–10），选择其代表变量或做降维（PCA）或只用一个（如保留 BMI，不同时用体重）。
5. **交互项**：考虑 `BMI × t`（BMI 是否改变随孕周上升速率）、`age × t` 等交互项；测试是否显著并改善拟合。

实操建议：建立一套候选模型（baseline，+age，+QC，+interactions），用 AIC/交叉验证与预测校准比较，再选一个既稳健又可解释的模型。

# 三、模型结构增强建议（具体）

* **固定效应**：`t`（孕周）、`BMI`、`age`、QC（L/M/N/GC）、可能的交互 `t*BMI`。变量都做中心化（例如 `t_c = t - mean(t)`）以便解释截距。
* **随机效应**：保留随机截距与随机斜率（对孕周），通常就够；若能观测到大量重复测量，也可以测试随机斜率对 BMI 的必要性（通常不需要）。
* **异方差（heteroscedasticity）**：残差方差可能随 QC 指标或孕周变化。可用 `varFunc`（R\:nlme）或在混合模型里建模 `σ^2 = f(L, M, ...)`，或在后续使用 bootstrap 来反映这种不等方差。
* **非线性**：若孕周-浓度关系非严格线性（早期上升快后期平缓），可用样条（spline）或局部多项式处理。
* **测量误差模型（可选，若要求高）**：把观测到的 `y_obs` 视为 `y_true + measurement_error`，用贝叶斯或 SIMEX 方法校正。如果不做复杂测量误差模型，用 parametric bootstrap 也能评估影响。

# 四、从 LMM 预测值到概率 P(Y ≥ 4%) —— 数学与实现细节

你已给出模型形式：

$$
y_{i,j} = (\beta_0 + u_{0i}) + \beta_1 t_{i,j} + \beta_2 \mathrm{BMI}_{i,j} + u_{1i} t_{i,j} + \varepsilon_{i,j}
$$

其中 $\varepsilon_{i,j}\sim N(0,\sigma_{\varepsilon}^2)$。

## 4.1 基本公式（两种常用情形）

**情形 A — 群体/新个体（没有个体BLUP）：求**群体水平概率（population-level）\*\*

* 用 **固定效应** 预测均值（不含随机效应）：

  $$
  \hat\mu_{\text{pop}}(t|X) = \hat\beta_0 + \hat\beta_1 t + \hat\beta_2 \mathrm{BMI} + \cdots
  $$
* 若要包含随机效应对总体变异的影响（对新个体的总体不确定性），总变异可取：

  $$
  \sigma_{\text{tot}} = \sqrt{\sigma_{\varepsilon}^2 + t^2\operatorname{Var}(u_1) + \operatorname{Var}(u_0) + 2 t\operatorname{Cov}(u_0,u_1)}
  $$

  （注意：若只预测均值，常用 $\sigma_\varepsilon$；要把随机效应不确定性也考虑进来，用上式。）
* 概率：

  $$
  P(Y\ge 4\% \mid t,X) \approx 1 - \Phi\!\left(\frac{4 - \hat\mu_{\text{pop}}(t|X)}{\sigma_{\text{tot}}}\right)
  $$

**情形 B — 已观测个体（可用 BLUP/û）：求**个体条件概率（subject-specific）\*\*

* 用个体的 BLUP（已估计的 $ \hat u_{0i}, \hat u_{1i}$）：

  $$
  \hat\mu_{\text{ind}}(t|X,i) = \hat\beta_0 + \hat u_{0i} + (\hat\beta_1 + \hat u_{1i}) t + \hat\beta_2\mathrm{BMI} + \cdots
  $$
* 这时残差方差可近似取 $\sigma_\varepsilon$（测量噪声），因为已条件于估计的随机效应：

  $$
  P(Y\ge 4\% \mid t,X,i) \approx 1 - \Phi\!\left(\frac{4 - \hat\mu_{\text{ind}}(t|X,i)}{\sigma_{\varepsilon}}\right)
  $$
* 备注：BLUP 有估计误差，若要把 BLUP 不确定性也计入，可用 parametric bootstrap 或用条件预测分布计算更精确的置信区间。

## 4.2 变换域模型（例如你对比例做 logit/arcsin）

* 若对 y 做了变换 $z = g(y)$ 并拟合 LMM 在 z 域，得出 $\hat\mu_z$ 与 $ \sigma_z$。要计算 $P(y \ge 4\%)$，需把阈值 4% 转到 z 域： $ z^* = g(4\%)$，然后

  $$
  P(y\ge 4\%) = P(z \ge z^*) = 1 - \Phi\!\left(\frac{z^* - \hat\mu_z}{\sigma_z}\right)
  $$
* 如果 $g$ 不是单调线性或逆变换是非线性的，用 Monte Carlo（模拟 z，然后逆变换到 y）更稳妥。

## 4.3 推荐实现（工程化步骤）

1. **准备**：从拟合模型导出固定效应 $\hat\beta$，随机效应方差/协方差矩阵 $Var(u)$，残差 σ̂，及每个个体的 BLUPs（若需）。
2. **选择预测情景**：对要预测的每一对 (subject, week) 决定用情形 A（群体）或情形 B（个体）。
3. **计算 μ̂**：按上式计算 μ̂\_pop 或 μ̂\_ind。
4. **计算 σ 用法**：

   * 若目标是对“新来孕妇”给通用建议（group-level），用 σ\_tot（含随机效应变异）；
   * 若目标是对已观测孕妇做个体化推荐，用 σ\_ε（条件残差）；
5. **计算 p\_hat**：用 `p_hat = 1 - scipy.stats.norm.cdf((4 - mu_hat) / sigma_used)`。
6. **不确定性**：用 parametric bootstrap：对模型参数按其估计分布（固定效应用 MVN，随机效应方差用近似）或对 y 直接模拟，重复计算 p\_hat，得到 p\_hat 的置信区间和 t\* 的置信区间。

## 4.4 选哪种 σ？（关键判断）

* **决策用（推荐时点给群体）**：用 `σ_tot` 包含随机效应变异，这会使得概率更保守（因为反映群体差异）。
* **个体化用（已观测且有多次测量）**：用条件 `σ_ε`，因为 BLUP 已解释个体差异，剩余就是测量/生物学噪声。

# 五、如何得到“最早达标周 t\*”及其不确定性

1. 对每个 subject，沿周序列（例如 10.0、10.25、...、24.0）计算 p\_hat(t)。
2. `t_star` = 最小 t 使 p\_hat(t) ≥ p\*（取 p\*=0.9 或 p\*=0.8）。若无满足，则标为“右删失”。
3. 用 bootstrap（模拟参数/数据）重复 B 次，得到 t\_star 分布，报告中位与 95%CI。
4. 若模型在变换域计算，先在变换域求 p\_hat，再逆变换或直接用蒙特卡洛在原域计算概率。

# 六、测量误差与异方差的处理（要点）

* **如果 QC 指标影响 σ**：在拟合模型时可允许 `σ` 随 QC 指标变化（用加权回归或分层残差），或者后续在计算 σ\_tot 时按 QC 分层调整（例如低 L 的 σ' = σ × 1.2）。
* **SIMEX / 测量误差模型**：若测量误差偏差不是纯随机（例如系统偏差），考虑更复杂方法（SIMEX 或贝叶斯测量误差模型）。
* **工程替代**：若不想复杂建模，用 parametric bootstrap 在不同噪声情景（σ, 1.2σ, 1.5σ）下评估 t\* 的敏感性。

# 七、实际编码参考（伪代码，Python 风格）

（关键计算 p\_hat 的核心片段）

```python
from scipy.stats import norm
# inputs: beta_hat (dict), var_u (matrix), sigma_eps, blup_u (if available)
def mu_pop(t, bmi, other):
    return beta_hat['b0'] + beta_hat['b1']*t + beta_hat['b2']*bmi + ... 

def sigma_tot(t):
    var_u0 = var_u[0,0]; var_u1 = var_u[1,1]; cov_u01 = var_u[0,1]
    return np.sqrt(sigma_eps**2 + var_u0 + t**2 * var_u1 + 2*t*cov_u01)

def p_pop(t, bmi, other):
    mu = mu_pop(t,bmi,other)
    s = sigma_tot(t)
    return 1 - norm.cdf((4.0 - mu)/s)

def p_ind(t, bmi, other, u0_hat, u1_hat):
    mu = beta_hat['b0'] + u0_hat + (beta_hat['b1'] + u1_hat)*t + beta_hat['b2']*bmi + ...
    return 1 - norm.cdf((4.0 - mu)/sigma_eps)
```

随后对每 subject 在周网格上计算 p，取最早满足阈值的 t。
