# 问题四：女胎异常判定方法

## 1. 问题重述与研究目标

针对女胎孕妇的 13/18/21 号染色体非整倍体（AB 列标注）判定问题，本文综合考虑 X/13/18/21 染色体 Z 值、GC 含量、测序读段数及相关比例、BMI 等变量，设计一套以 **高召回率为优先目标** 的异常判定策略，用于疾病初筛。同时结合规则判定与概率模型，提出强阳性标志与复核流程，以降低漏检风险并兼顾临床可操作性。

## 2. 数据来源与预处理

* **数据集**：`附件B.csv`（女胎样本）。
* **关键字段映射**：

  * 染色体 Z 值：`Q/R/S/T` → Z13/Z18/Z21/X；
  * GC 含量：`X/Y/Z` → GC13/GC18/GC21；
  * 测序与比例指标：`L/M/N/O/AA`；
  * 体征指标：`K`（BMI）、`J`（孕周）；
  * 标签：`AB` → 异常类型（T13/T18/T21）。
* **预处理策略**：

  * 字段命名与类型统一；
  * 质控指标（GC、读段数、比对率、重复率）仅作提醒，不做硬性剔除；
  * 构造衍生特征，包括：极值与绝对值（`zmax, zabsmax`）、均值与标准差（`zmean, zstd`）、非线性变换（平方、绝对值）、阈值指示（`I(Z>2.5), I(Z>3)`）、交互与比值（`Z×BMI, Z×GC, Z/BMI`）。

## 3. 判定方法设计

1. **规则判定（强阳性标志）**

   * 若 `max(Z13, Z18, Z21) ≥ 3`，则直接判定为高风险异常，进入确证性检查。
2. **概率模型（初筛排序）**

   * 基于“Z 系及衍生特征”构建逻辑回归模型，采用 Isotonic 回归进行概率校准，输出风险得分 $p\in[0,1]$。
3. **阈值策略（多模式并行）**：

   * **高召回模式**：在 PR 曲线上选择 Recall≈0.7/0.8/0.9 时对应的最优 Precision 阈值，用于疾病初筛。
   * **平衡模式**：采用 F1 最优阈值（约 $p≈0.097$），兼顾 Precision 与 Recall。
   * **高精度模式**：若 Precision≥0.30，可选取对应 Recall 最大的阈值，供确诊前置参考。
   * **Top-K 模式**：按风险得分排序，选取前 5%/10% 样本作为高危人群，便于资源调度与复核优先级管理。

## 4. 实验结果

* **概率模型表现**（Z 系+衍生特征，Isotonic 校准）：

  * AUC≈0.72，AP≈0.18，较原始特征显著提升。
* **平衡模式（F1 最优，p≈0.097）**：

  * Recall≈0.56，Precision≈0.16，Accuracy≈0.70。
* **固定阈值（p=0.1086）**：

  * Recall≈0.25，Precision≈0.19，Accuracy≈0.84，更偏保守判定。
* **规则法（z\_max≥3）**：

  * Recall≈0.12，Precision≈0.09，仅适合作为强阳性提示，而非独立筛查标准。
* **Top-K 策略**：在 Top-5%/10% 采样下，Recall 明显提升，Precision 保持中等水平，适合作为复核资源配置的补充方案。

## 5. 错误样本分析

* **假阴性（FN）**：多数集中在 Z 值 2–3 的临界区间，BMI 偏高或测序深度不足可能导致信号减弱。
* **假阳性（FP）**：部分样本与质控异常（GC 偏倚、低比对率、高重复率）相关。
* **结论**：模型错误主要源于临界样本，而非完全随机，表明通过阈值分层和复核流程能够有效降低风险。

## 6. 判定流程建议

1. **强阳性直判**：若 `z_max ≥ 3` 且 $p ≥ 0.10$，直接进入确证性检查。
2. **初筛（召回优先）**：若 $p ≥ 0.097$，判定为“可疑”，进入复检或人工复核流程。
3. **低风险**：其余样本；若质控提示异常，则建议重采，而非直接判定为正常。
4. **可选扩展**：结合孕周/质控水平进行分层校准，并在资源允许时采用 Top-K 机制优先复核。

## 7. 讨论与局限

* **数据稀缺性**：异常样本比例极低，Z 值与异常标签的统计分离有限，导致 Precision 与 Recall 难以同时优化。
* **策略选择**：本文采用“召回优先”的初筛策略，并辅以强阳性规则和复核流程，以降低漏检风险。
* **改进方向**：若能获得更多异常样本或引入实验批次效应校正（如按 GC/reads 分桶标准化 Z 值），模型性能有望进一步提升。
