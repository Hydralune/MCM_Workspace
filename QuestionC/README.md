# NIPT无创产前检测时点选择与胎儿异常判定

## 项目概述

本项目基于无创产前检测(NIPT)数据，研究胎儿染色体浓度与孕妇生理指标的关系，建立数学模型优化NIPT检测时点，提高检测准确性并降低潜在风险。

## 问题背景

NIPT通过检测孕妇血液中的胎儿游离DNA片段来判断胎儿染色体是否存在异常。本项目主要关注：
- 唐氏综合征(21号染色体异常)
- 爱德华氏综合征(18号染色体异常) 
- 帕陶氏综合征(13号染色体异常)

### 关键判定标准
- **男胎Y染色体浓度≥4%**时检测结果基本准确
- **早期发现(≤12周)**风险较低
- **中期发现(13-27周)**风险较高
- **晚期发现(≥28周)**风险极高

## 数据集说明

### 原始数据特征
- **样本数量**: 1082条男胎有效记录
- **时间跨度**: 孕周11-29周
- **BMI范围**: 20.7-46.9 (平均32.3)
- **Y染色体浓度**: 0.01%-23.4% (平均7.7%)

### 关键字段解释

| 字段名 | 含义 | 数据类型 |
|--------|------|----------|
| subject_id | 孕妇唯一标识 | 字符串 |
| maternal_age | 孕妇年龄 | 整数 |
| maternal_height_cm | 孕妇身高(cm) | 浮点数 |
| maternal_weight_kg | 孕妇体重(kg) | 浮点数 |
| bmi | 身体质量指数 | 浮点数 |
| gestational_week | 孕周数(周+天转换为小数) | 浮点数 |
| y_concentration | Y染色体浓度(%) | 浮点数 |
| y_zscore | Y染色体Z值 | 浮点数 |

## 研究问题

### 问题1: 相关性分析
**目标**: 分析胎儿Y染色体浓度与孕妇孕周数和BMI的关系

**建模方法**:
- 多元线性回归模型
- 广义加性模型(GAM)
- 线性混合效应模型(处理重复测量数据)

### 问题2: BMI分组与最佳检测时点
**目标**: 对男胎孕妇BMI进行合理分组，确定每组最佳NIPT时点

**优化策略**:
- 风险量化: 早期=1分, 中期=5分, 晚期=10分
- 约束条件: Y染色体浓度≥4%
- 求解每组最早达标时间，权衡检测成功率与风险

### 问题3: 多因素综合优化
**目标**: 综合考虑身高、体重、年龄等因素，优化BMI分组和检测时点

**方法**:
- 扩展混合效应模型包含更多协变量
- 特征选择识别显著影响因素
- 重新优化每组最佳检测时点

### 问题4: 女胎异常判定
**目标**: 建立女胎染色体异常的判定方法

**分类方法**:
- 规则基方法: Z值阈值判定
- 机器学习: 逻辑回归、随机森林、XGBoost
- 特征工程: 染色体Z值、GC含量、读段数等

## 数据预处理

### 清洗步骤
1. **孕周转换**: 将"11w+6"格式转换为小数(11.86周)
2. **缺失值处理**: 女胎数据Y染色体相关字段为空，天然分组
3. **异常值检测**: 使用Z-score方法识别异常值
4. **重复测量**: 识别同一孕妇的多次检测记录

### 特征工程
- **BMI分组**: [20,28), [28,32), [32,36), [36,40), 40+
- **孕周分段**: 早期(≤12周), 中期(13-27周), 晚期(≥28周)
- **标准化**: 对连续变量进行标准化处理
