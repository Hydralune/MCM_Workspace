### **问题四：女胎异常判定方法 - 详细执行步骤**

#### **核心思路**

我们将这个问题构建为一个**监督学习分类任务**。
*   **目标 (Y)**：女胎是否异常（基于AB列）。这是一个二分类问题（正常 vs. 异常），也可以看作一个多分类问题（正常, T13, T18, T21）。**建议从更简单、更稳健的二分类问题入手。**
*   **特征 (X)**：题目中提到的所有指标（Z值、GC含量、读段数、BMI等）。
*   **挑战**：数据**极度不平衡**。异常样本（正样本）的数量会远远少于正常样本（负样本），这是解决问题的关键。

---

### **第一步：数据准备与特征工程 (Data Preparation)**

这是最基础也是最关键的一步。

1.  **使用预处理的女胎数据**：
    在数据预处理文件夹下使用已经处理的

2.  **创建目标变量 (Target Variable, `y`)**：
    *   在 `female_data` 中，找到 **AB列（染色体非整倍体）**。
    *   创建一个新的二分类目标列，命名为 `is_abnormal`。
    *   **规则**：如果AB列是 `T13`, `T18`, `T21` 中的任意一个，`is_abnormal` 设为 `1` (异常)；如果AB列为空白，`is_abnormal` 设为 `0` (正常)。
    *   **检查类别分布**：计算 `is_abnormal` 中 `0` 和 `1` 的数量。你会发现 `1` 的数量非常少，这就是**类别不平衡**问题。

3.  **构建特征矩阵 (Feature Matrix, `X`)**：
    *   从 `female_data` 中选取题目要求的所有列作为特征：
        *   **Z值**: Q (13号), R (18号), S (21号), T (X染色体)。
        *   **GC含量**: X (13号), Y (18号), Z (21号)。
        *   **读段数相关指标**: L, M, N, O, AA。
        *   **孕妇生理指标**: K (BMI), C (年龄)等。
    *   **处理缺失值**：检查这些特征列中是否有缺失值(NaN)。如果有，需要进行处理。最简单的策略是**中位数或均值填充**。
        ```python
        # 伪代码示例
        from sklearn.impute import SimpleImputer
        imputer = SimpleImputer(strategy='median')
        X_imputed = imputer.fit_transform(X)
        ```

4.  **数据拆分 (Train-Test Split)**：
    *   将数据拆分为训练集和测试集，例如80%训练，20%测试。
    *   **关键操作**：在拆分时，必须使用 `stratify` 参数，确保训练集和测试集中的异常样本比例与原始数据一致。这对于不平衡数据至关重要。
        ```python
        from sklearn.model_selection import train_test_split
        X_train, X_test, y_train, y_test = train_test_split(
            X_imputed, y, test_size=0.2, random_state=42, stratify=y
        )
        ```

### **第二步：探索性数据分析 (EDA)**

在建模前，通过可视化理解数据特性。

1.  **特征分布对比**：
    *   对于最重要的特征（尤其是**Z值**），绘制**箱形图 (Box Plot)**，比较正常组 (`is_abnormal=0`) 和异常组 (`is_abnormal=1`) 的分布差异。
    *   **预期发现**：你会看到，对于异常样本，其对应染色体的Z值会显著高于正常样本。例如，T21异常样本的S列（21号Z值）会非常高。这验证了Z值的有效性。

### **第三步：建模策略与实施 (Modeling)**

由于数据不平衡，不能直接使用标准模型和评估方法。

1.  **选择评估指标 (Evaluation Metrics)**：
    *   **放弃准确率(Accuracy)**：因为它会被大量正常样本主导，产生误导性结果。
    *   **采用**：
        *   **混淆矩阵 (Confusion Matrix)**：查看真阳性(TP)、假阳性(FP)、真阴性(TN)、假阴性(FN)。
        *   **精确率 (Precision)**：`TP / (TP + FP)`，预测为异常的样本中有多少是真的。
        *   **召回率 (Recall)**：`TP / (TP + FN)`，所有真实异常的样本中，模型找出了多少。**这是本问题中最重要的指标之一，因为漏诊（假阴性）的后果很严重。**
        *   **F1分数 (F1-Score)**：精确率和召回率的调和平均值。
        *   **AUC-ROC曲线**：评估模型整体的分类能力。

2.  **建立基准模型 (Baseline Model)**：
    *   模拟临床的简单规则，作为比较的底线。
    *   **规则**：如果 `Q列Z值 > 3` 或 `R列Z值 > 3` 或 `S列Z值 > 3`，则判定为异常(1)，否则为正常(0)。
    *   在测试集上评估这个简单规则的性能，计算其召回率和精确率。

3.  **选择并训练机器学习模型**：
    *   推荐使用对非线性关系和特征交互不敏感的**树模型**，如**随机森林 (Random Forest)** 或 **XGBoost**。它们强大且易于解释。
    *   **处理类别不平衡**：
        *   **方法一（推荐，最简单）**：在模型初始化时设置 `class_weight='balanced'`。这会自动给少数类（异常样本）更高的权重。
            ```python
            from sklearn.ensemble import RandomForestClassifier
            model = RandomForestClassifier(class_weight='balanced', random_state=42)
            ```
        *   **方法二（进阶）**：使用**SMOTE (Synthetic Minority Over-sampling Technique)** 对**训练数据**进行过采样。注意：**SMOTE只能用于训练集，绝不能用于测试集**。
    *   **训练模型**：
        ```python
        model.fit(X_train, y_train)
        ```

### **第四步：模型评估与解释 (Evaluation & Interpretation)**

1.  **在测试集上评估**：
    *   用训练好的模型对 `X_test` 进行预测。
        ```python
        y_pred = model.predict(X_test)
        y_prob = model.predict_proba(X_test)[:, 1] # 获取异常的概率
        ```
    *   **生成报告**：
        ```python
        from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score
        print(confusion_matrix(y_test, y_pred))
        print(classification_report(y_test, y_pred))
        print("AUC Score:", roc_auc_score(y_test, y_prob))
        ```
    *   **对比基准模型**：比较你的机器学习模型和基准模型的性能，特别是**召回率**。你的模型应该有显著提升。

2.  **特征重要性分析 (Feature Importance)**：
    *   这是树模型的一个巨大优势。你可以查看哪些特征对模型的决策贡献最大。
        ```python
        import matplotlib.pyplot as plt
        import pandas as pd

        feature_importances = pd.Series(model.feature_importances_, index=X.columns)
        feature_importances.nlargest(10).plot(kind='barh')
        plt.show()
        ```
    *   **预期发现**：`S列(21号Z值)`、`R列(18号Z值)`、`Q列(13号Z值)` 将会是**最重要**的特征，这与临床知识完全一致，证明了模型的有效性。其他指标（GC含量、BMI等）可能会有较小的贡献。
