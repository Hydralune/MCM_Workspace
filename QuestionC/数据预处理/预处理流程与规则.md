# 数据预处理流程与规则（问题一）

本文档描述 `数据预处理/` 中的预处理逻辑、阈值与输出，适用于：

- 附件（男性）：`附件.csv`（或同名 Excel/不同编码的 CSV）
- 附件B（女性）：`附件B.csv`

## 数据加载与列名标准化

- **多编码读取**：优先读取 Excel；否则依次尝试 `utf-8-sig / utf-8 / gbk / gb2312 / cp936` 加载 CSV。
- **列名标准化**：将题目中的中文列名映射为字母位点（`A`~`AE`），以便稳健处理。关键位点：
  - `J`: 孕周字符串（如“13w+6”、“13周+6天”等）
  - `K`: BMI
  - `L`~`O`: 读段数与比对相关指标
  - `P`: GC 含量
  - `T`~`W`: X/Y 相关 Z 值与浓度
  - `AA`: 过滤比例

## 字段衍生与清洗

- **删除冗余列**：删除 `F`（末次月经时间）。理由：题中已提供更准确的孕周数据（`J`）。
- **孕周解析**：`J` → `gestational_week`（浮点周），支持“13w+6/13w/13+6/13/13周+6天”等，无法解析则为空。
- **编码扩展**：
  - 孕次（`AC`）、产次（`AD`）：将“≥3、>=3、≧3”等规范化为整数（最小 3），其他尝试转为数值，失败置空。
  - 妊娠方式（`G`）→ `conception_mode`，并衍生 `ivf_flag`（包含“IVF/试管/人工”记 1，否则 0）。
- **BMI 复算与一致性**：由身高体重复算 `bmi_recalc`；若原 `bmi` 缺失或与复算差异 > 0.5，则替换为复算值；保留 `bmi_mismatch` 标记。

## 性别划分与列保留/重命名

- **男性样本**：以 `V`（Y 浓度）非空为男性；重命名与保留：
  - `B→subject_id`, `C→maternal_age`, `D→maternal_height_cm`, `E→maternal_weight_kg`, `G→conception_mode`,
    `K→bmi`, `J→gestation_str`, `H→draw_date`, `I→draw_index`, `V→y_concentration`, `U→y_zscore`，
    以及与质控相关的 `L,M,N,O,P,X,Y,Z,AA`。
- **女性样本**：以 `V`（Y 浓度）为空为女性；重命名与保留：
  - `B→subject_id`, `C→maternal_age`, `D→maternal_height_cm`, `E→maternal_weight_kg`, `G→conception_mode`,
    `K→bmi`, `J→gestation_str`, `H→draw_date`, `I→draw_index`, `T→x_zscore`, `W→x_concentration`，
    以及与质控相关的 `L,M,N,O,P,X,Y,Z,AA`。

## 基础质控筛选（QC Filtering）

- 规则：`39% ≤ GC(P) ≤ 62%`，`L > 5e5`，`0.40 ≤ M ≤ 0.995`，`N ≤ 0.80`。

## 异常值处理

- **数值类型统一**：关键数值字段统一 `to_numeric(errors='coerce')`。
- **Y 浓度异常值过滤（男性）**：按分位数剔除极端值：`y_concentration` 去除 P0.5 以下与 P99.5 以上。
- **关于分箱**：当前不对 `y_concentration` 做分箱，仅做分位数裁剪。

## 缺失值处理与去重

- **必需字段缺失行删除**：
  - 男性：删除 `gestational_week / bmi / y_concentration` 任一缺失的样本；
  - 女性：删除 `gestational_week / bmi` 任一缺失的样本。
- **同孕周合并去重**：
  - 计算 `gestational_week_round = round(gestational_week, 1)`；
  - 以 `subject_id + gestational_week_round` 分组：数值列取均值；`gestation_str / draw_date / draw_index` 取首个；
  - 用于整合同一受试者在非常接近孕周的多次检测，降低重复影响。

## 输出

- 脚本与输出文件：
  - 男性：`preprocess_male.py` → `male_cleaned.csv`、`male_stats.csv`、`male_prep_log.md`
  - 女性：`preprocess_female.py` → `female_cleaned.csv`、`female_stats.csv`、`female_prep_log.md`
  - 兼容旧流程：`preprocess_data.py` 主函数输出 `q1_male_cleaned.csv`、`q1_male_stats.csv`、`q1_prep_log.md`

## 运行示例（Windows cmd）

- 仅处理男性：

```bash
python 数据预处理/preprocess_male.py
```

- 仅处理女性：

```bash
python 数据预处理/preprocess_female.py
```


## 可调项与扩展建议
- 阈值可按数据分布调整（如 `L`、`M/N`、`AA`）；
- 可为 `draw_index`、孕周等衍生分箱特征用于后续建模；
- 如需为 `y_concentration` 引入“分箱/稳健缩放/分位数变换”，建议在建模阶段另行开关控制，避免影响通用统计特征。
